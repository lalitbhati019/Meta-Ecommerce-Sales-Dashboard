# 📊 Meta Ecommerce Sales Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze eCommerce sales performance. It transforms raw sales data into meaningful business insights using Power Query, DAX, and interactive visualizations.

The dashboard enables users to monitor sales performance, profit trends, customer purchases, product categories, payment methods, and state-wise revenue through dynamic filters.

---

## 🛠 Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Visualization

---

## 📈 Dashboard Features

✔ Sales KPI Cards

- Total Sales Amount
- Total Quantity Sold
- Total Profit
- Average Order Value (AOV)

✔ Interactive Filters

- Quarter Filter
- State Filter

✔ Visualizations

- Sales by State
- Monthly Profit Analysis
- Profit by Sub-Category
- Quantity by Product Category
- Customer-wise Sales
- Quantity by Payment Mode

---

## 📊 Key Business Insights

- Maharashtra generated the highest sales.
- Clothing contributed the highest quantity sold.
- January recorded the highest profit among the selected months.
- Printers generated the maximum profit among all sub-categories.
- COD and UPI were the most preferred payment methods.
